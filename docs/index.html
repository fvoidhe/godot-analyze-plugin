Godot Analyze

A type-aware GDScript and Godot 4 toolkit for IntelliJ IDEA and Rider.

Install Report an issue

Features

  • Type-Aware Code InsightTypes are inferred across scripts, scenes and the engine API. Completion, Go To Declaration and Find Usages follow class_name, extends, preload(), get_node() / $Node paths and exported properties.
  • Compiler-Grade Inspections25+ inspections modeled on the Godot compiler – incompatible assignment, return and argument types, wrong argument counts, unresolved members, override signature mismatches, assignments to constants, unreachable code, shadowed identifiers, invalid annotations, and more.
  • Smart CompletionEngine and project classes, members, signals, enums and res:// paths. Picking filter, map, any, all, sort_custom or reduce expands a ready-to-fill lambda.
  • Inlay HintsInferred node types of get_node(), resolved resource types of preload(), parameter names at call sites, and declared types of exported properties right inside .tscn / .tres files.
  • Rename RefactoringRename functions, global classes and scene nodes without breaking references in scripts and scenes.
  • Scene and Resource Files.tscn, .tres, .import and project.godot are fully parsed – highlighting, navigation for ExtResource, SubResource, node paths and uid:// references.
  • Signal ConnectionsGutter markers link [connection] entries in scenes with the script methods they call, in both directions.
  • Override MarkersGutter icons for overriding and overridden functions, and for nodes overridden in inherited scenes.
  • Scene Tree Tool WindowBrowse the node tree of the current scene with Godot's own node icons, attached scripts, unique names, visibility and connected signals.
  • Engine DocumentationQuick Documentation and parameter info come from the class reference of your Godot version, in both IntelliJ IDEA and Rider.
  • FormatterGodot-style indentation for blocks, brackets and continuation lines, plus blank-line rules between declarations.
  • Run ConfigurationsRun the project or the current scene with any registered Godot installation; resources are imported before launch.
  • DebuggerSet breakpoints in GDScript and debug with the IDE debugger – stepping, call stacks and variables, for Godot 4.0 and newer.
  • Godot Editor IntegrationOpen or bring forward the Godot editor and switch the project's Godot version from the main toolbar. Manage multiple installations in Settings → Languages & Frameworks → Godot Installations.
  • HelpersCode folding, commenting, spell checking, smart Enter in strings, copy res:// path, and more.

Install

  1. Open Settings → Plugins → Marketplace in your IDE.
  2. Search for Godot Analyze and click Install.
  3. Open a folder that contains project.godot.

Requires a JetBrains IDE 2026.2 or newer and Godot 4.x.

Feedback

Bugs and ideas go to the issue tracker. For bugs, please include your IDE, plugin and Godot versions, and a minimal snippet if you can.
