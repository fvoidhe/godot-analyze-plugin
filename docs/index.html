Godot Analyze

GDScript and Godot scene support for JetBrains IDEs.

Install Report an issue

Features

GDScript editing

  • Syntax and semantic highlighting, folding
  • Completion for engine and project symbols
  • Go to declaration, find usages, rename
  • Inlay hints for get_node(), preload() and arguments
  • Quick documentation from the engine API
  • Formatter with Godot-style indentation

Static analysis

  • Type inference across scripts and scenes
  • 25+ inspections mirroring the Godot compiler
  • Type mismatches, unresolved members, unreachable code
  • Override signature checks with gutter markers

Scenes and resources

  • .tscn, .tres, .import, project.godot
  • Navigate ExtResource, SubResource and node paths
  • Signal connection markers between scenes and scripts
  • Scene tree tool window

Run and debug

  • Run configurations, run the current scene
  • GDScript breakpoints in the IDE debugger
  • Open the Godot editor from the toolbar
  • Manage multiple Godot installations

Install

  1. Open Settings → Plugins → Marketplace in your IDE.
  2. Search for Godot Analyze and click Install.
  3. Open a folder that contains project.godot.

Requires a JetBrains IDE 2026.2 or newer and Godot 4.x.

Feedback

Bugs and ideas go to the issue tracker. For bugs, please include your IDE, plugin and Godot versions, and a minimal snippet if you can.
