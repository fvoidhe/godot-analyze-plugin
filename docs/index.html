Godot Analyze

A type-aware GDScript and Godot 4 toolkit for IntelliJ IDEA and Rider.

Install Report an issue

Features

Type-Aware Code Insight

Types inferred across scripts, scenes and the engine API.

Compiler-Grade Inspections

25+ checks modeled on the Godot compiler.

Smart Completion

Classes, members, signals, enums and res:// paths.

Inlay Hints

Node, resource and parameter types shown inline.

Rename Refactoring

Functions, global classes and scene nodes, references included.

Scene and Resource Files

Full support for .tscn, .tres, .import and project.godot.

Signal Connections

Jump between scene connections and their handler methods.

Override Markers

Gutter icons for overridden functions and inherited nodes.

Scene Tree Tool Window

The current scene's node tree, with Godot's own icons.

Engine Documentation

Class reference for your Godot version, in IntelliJ IDEA and Rider.

Formatter

Godot-style indentation and blank lines.

Run Configurations

Run the project or the current scene.

Debugger

GDScript breakpoints in the IDE debugger.

Godot Editor Integration

Open the editor and switch Godot versions from the toolbar.

Helpers

Folding, commenting, spell checking and more.

Install

  1. Open Settings → Plugins → Marketplace in your IDE.
  2. Search for Godot Analyze and click Install.
  3. Open a folder that contains project.godot.

Requires a JetBrains IDE 2026.2 or newer and Godot 4.x.

Feedback

Bugs and ideas go to the issue tracker. For bugs, please include your IDE, plugin and Godot versions, and a minimal snippet if you can.
